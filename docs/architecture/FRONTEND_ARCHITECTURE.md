# Архитектурная спецификация фронтенда (Metabolic Atlas)

Данный документ описывает структуру, компоненты, сервисы и правила взаимодействия на фронтенде проекта **Metabolic Atlas** (стек: Angular 22 standalone, signals, zoneless, SCSS, SVG-визуализация).

---

## 1. Общая слоистая архитектура

Фронтенд структурирован по принципу **Feature-Driven / Layered Architecture**:

```
┌────────────────────────────────────────────────────────────────────────┐
│                                 APP                                    │
│                 (App Component • Routes • Providers)                   │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
       ┌────────────────────────────┼────────────────────────────┐
       ▼                            ▼                            ▼
┌──────────────┐             ┌──────────────┐             ┌──────────────┐
│   LAYOUT     │             │   FEATURES   │             │    SHARED    │
│ Header       │             │ ├── atlas    │             │ Chemical-    │
│ Sidebar      │             │ ├── textbook │             │   Structure  │
│ Footer       │             │ ├── search   │             │ UI Utilities │
│ Switchers    │             │ └── pathways │             │ Shared Pipes │
└──────────────┘             └──────┬───────┘             └──────────────┘
                                    │
       ┌────────────────────────────┴────────────────────────────┐
       ▼                                                         ▼
┌──────────────────────────────┐          ┌──────────────────────────────┐
│             CORE             │          │             DATA             │
│ Api • Locale • Theme • State │          │ In-Memory Biological Data    │
│ Domain (Metabolism Service)  │          │ Metabolites • Reactions • SVG│
└──────────────────────────────┘          └──────────────────────────────┘
```

1. **`layout/`** — Скелет и постоянное обрамление страницы (Header, Sidebar, Footer, переключатели языка и темы).
2. **`features/`** — Самостоятельные бизнес-экраны и разделы, загружаемые лениво (`loadComponent`):
   - **`atlas/`** — Интерактивная векторная карта метаболизма человека (зум, панорамирование, секторы, реакции, инспектор).
   - **`textbook/`** — Онлайн-учебник биохимии с главами, теоретическим материалом и глубокими ссылками на карту.
   - **`search/`** — Глобальный поиск по метаболитам, реакциям и ферментам.
   - **`pathways/`** — Каталог метаболических путей.
   - **`entities/`** — Паспорта отдельных биохимических сущностей.
3. **`shared/`** — Библиотека чистых UI-компонентов, повторно используемых в разных фичах (`ChemicalStructureComponent` используется как в инспекторе атласа, так и в статьях учебника).
4. **`core/`** — Инфраструктурные сервисы-синглтоны: клиент REST API (`ApiService`), темы (`ThemeService`), язык (`LocaleService`), межкомпонентное состояние (`AtlasStateService`, `SidebarService`) и домен метаболизма (`MetabolismService`).
5. **`data/`** — Модульные биологические датасеты (36 метаболитов, 17 кофакторов, реакции углеводного и энергетического обмена, координаты, SVG-геометрия).

## 3. Описание ключевых компонентов и сервисов

### 3.1. Ядро карты: `AtlasShellComponent` и вспомогательные сервисы

`AtlasShellComponent` — главный дирижёр карты. Его размер оптимизирован до ~390 строк за счёт выноса логики в два специализированных сервиса:

- **`AtlasViewportService`:**
  - Отвечает за систему координат, масштабирование (15%..250%) и панорамирование.
  - Поддерживает **screen-centric зум** (от центра экрана через кнопки HUD) и **cursor-relative зум** (колёсиком мыши относительно точки курсора).
  - Управляет глобальными слушателями `mousemove` / `mouseup` с троттлингом через `requestAnimationFrame`.
  - Предоставляет плавные методы фокусировки камеры: `focusOnNode()`, `focusOnTca()`, `focusOnOxphos()`, `focusOnSector()`, `focusOnPdh()`, `focusOnGalactose()`, `focusOnGlycogen()`, `focusOnFructose()`.
  - Вычисляет текущий уровень детализации (`lodLevel`: 1 = Macro, 2 = Meso, 3 = Micro).

- **`AtlasHighlightService`:**
  - Управляет активным выбором: выбранная реакция (`selectedReaction`), выбранный метаболит (`selectedMetabolite`), активная вкладка инспектора (`activeTab`).
  - Вычисляет реактивные $O(1)$ `Set`-множества для быстрой подсветки: `dimmedNodeIds` (узлы, которые нужно приглушить), `dimmedReactionIds`, `selectedSubstrateIds`, `selectedProductIds`.
  - Реализует фильтрацию по энергетическим носителям (`NADH`, `FADH2`, `GTP`, `ATP`) через регулярные выражения `CARRIER_PATTERNS`.
  - Осуществляет поиск метаболитов по официальным названиям, синонимам, аббревиатурам и кодам (`findMetaboliteByName`).

### 3.2. Оверлеи и панели (`features/atlas/overlays/`)

- **`AtlasZoomControlsComponent`:** плавающая HUD-панель в правом нижнем углу. Содержит кнопки быстрого масштабирования, сброса к 100% и перехода в макро-режим (38%).
- **`AtlasContextPillComponent`:** плашка в левом верхнем углу. Отображает название текущего выбранного пути и текущий уровень LOD.
- **`AtlasInspectorComponent`:** правая выдвижная панель. Показывает формулу вещества, ферменты, стехиометрию, дельта G, коферменты и регуляторы. Внутри переключает `ma-reaction-inspector` и `ma-metabolite-inspector`.

### 3.3. Векторные SVG-слои (`features/atlas/svg/`)

Все дочерние SVG-компоненты объявлены как **атрибуты на `<g>`** (например, `<g ma-metabolite-tile [met]="met"></g>`), что позволяет рендерить их прямо внутри родительского SVG без создания невалидных промежуточных DOM-элементов.

## 4. Кросс-фичевая интеграция: Учебник ⇄ Атлас

Проект объединяет академическое обучение с интерактивной визуализацией:

1. **Из Учебника в Карту (Deep Linking):**
   - Главы и статьи учебника (`features/textbook`) содержат ссылки с параметрами фокусировки (например, `/atlas?focus=PW-TCA-CYCLE`).
   - Нажатие на ссылку переключает роут и заставляет `AtlasShellComponent` плавно спозиционировать вьюпорт на изучаемом процессе.
2. **Формулы молекул (`shared/components/chemical-structure`):**
   - Компонент `ma-chemical-structure` принимает векторную SVG-строку структуры и отображает её в одинаковом академическом стиле как в инспекторе карты, так и в статьях учебника.
3. **Из Карты в Учебник:**
   - В инспекторе метаболита/реакции предусмотрены ссылки вида *«Читать в учебнике: Глава 3. Цикл Кребса»*, ведущие на роут `/textbook/ch-tca`.

## 5. Железные правила разработки SVG-компонентов

При создании или редактировании любых компонентов карты **строго соблюдаются правила**:

1. **`ViewEncapsulation.Emulated` везде:** Использование `ViewEncapsulation.None` на хост-компонентах запрещено, так как селектор `:host` ломается в глобальной области видимости и приводит к схлопыванию контейнера в `0×0`.
2. **Явные `fill` и `stroke`:** Дефолтный цвет фигур SVG — чёрный (`#000000`). Каждая векторная фигура (`<rect>`, `<path>`, `<circle>`) в дочернем компоненте обязана иметь явный `fill: ...` в своём SCSS-файле. Невидимые кликабельные области должны иметь `fill: transparent`.
3. **Запрет `display: contents;` на трансформируемых `<g>`:** В SVG применение CSS-свойства `display: contents;` к тегу `<g>` заставляет движок браузера отбрасывать атрибут `transform="translate(x, y)"`, из-за чего координаты сбрасываются в `(0, 0)`.
4. **Глобальные `<defs>` остаются в `atlas-shell.component.html`:** Маркеры стрелок (`#rx-arrowhead`, `#cofactor-arrowhead`) и фильтры свечения объявляются один раз в корневом SVG и резолвятся дочерними элементами через `url(#id)`.
